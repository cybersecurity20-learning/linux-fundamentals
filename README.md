# Linux Fundamentals

The project is based on my studies with NDG Linux Unhatched.

## Learning Objectives

- Understand Linux fundamentals.
- Navigate the Linux terminal.
- Manage files and directories.
- Create, copy, move, and delete files.
- Understand Linux file permissions.
- Learn basic system administration commands.

## Linux Terminal

Learning how to interact with the Linux operating system using command-line instructions.

## File and Directory Management

Practicing commands to create, organize, copy, move, and manage files and directories.

## File Permissions

Learning how Linux permissions work and practicing commands such as:

- ls -l
- chmod
- Read, Write, Execute permissions.
